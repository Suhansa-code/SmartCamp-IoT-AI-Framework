# Edge Gateway — complete, pinned runtime dependency set (used by Dockerfile).
#
# scripts/requirements.txt is the loose dev list and is deliberately
# incomplete: importing scripts/api.py pulls in the DEM reader and the
# XGBoost model, so rasterio/pyproj/xgboost/scikit-learn/matplotlib are
# import-time requirements of the API, not optional extras.
#
# Two pins are load-bearing and must be bumped together with a retrain:
#   xgboost      — prediction-models/models/xgboost_model.pkl carries a
#                  booster serialised by 3.2.0; an older xgboost cannot
#                  read it, which the API surfaces as a 502 on /predict.
#   scikit-learn — the random-forest / decision-tree / logistic .pkl
#                  files are pickled by 1.4.2; a different minor emits
#                  InconsistentVersionWarning or fails to unpickle.
# scikit-learn 1.4.2 is built against the numpy 1.x ABI, which is what
# holds numpy below 2 here.
