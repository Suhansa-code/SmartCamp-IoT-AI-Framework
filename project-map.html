What is SDRC-Box?

An integrated IoT + AI framework for rapid deployment in disaster-stricken areas. It connects ESP32 sensor nodes to an edge gateway (Intel NUC) for flood prediction, a Raspberry Pi 5 for camp management, and an AWS cloud platform for centralized admin dashboards and psycho-educational support. The research novelty is SAAMP (Semantic-Aware Adaptive Message Prioritization) for reliable IoT communication under degraded network conditions.

Tech Stack

Edge/Middleware: Python 3.11, FastAPI, Flask, GeoPandas, NetworkX
ML/AI: XGBoost, scikit-learn, LightGBM, Isolation Forest, Joblib
Camp Server: Node.js, Express, React 18 + Vite, SQLite (better-sqlite3)
Cloud: Next.js 16, React 19, Express, Turso/libSQL, Recharts
IoT: MQTT (EMQX Serverless), ESP32 (Arduino/C++, planned)
Infra: GitHub Actions, Tailwind CSS 4, Framer Motion

Communication Protocol

Sensors → Serial/UART → Edge Gateway → MQTTS :8883 → EMQX Broker → RPi & Cloud VM. The RPi uses the SAAMP protocol layer for adaptive QoS and offline buffering. Cloud-to-cloud communication uses HTTPS (REST).
